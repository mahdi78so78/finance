# 💰 Finance Cloud

A modern, responsive, and lightweight personal finance management application built to help users track their income, expenses, budgets, and savings goals.

Finance Cloud provides a simple and intuitive interface for managing personal finances, with cloud-based data storage and individual user accounts.

## ✨ Features

- **Income & Expense Tracking** – Record, edit, and manage daily financial transactions.
- **Financial Reports** – View income, expenses, balances, and monthly financial summaries.
- **Category Management** – Organize transactions by categories.
- **Tags** – Add custom tags to transactions for better organization.
- **Monthly Budgets** – Set spending limits for different expense categories.
- **Savings Goals** – Create savings goals and track your progress.
- **Cloud Storage** – Securely store personal financial data using Supabase.
- **User Authentication** – Individual accounts with email and password authentication.
- **CSV Import & Export** – Import transactions and create backups of financial data.
- **Bank SMS Import** – Parse and import supported Blu bank transaction messages.
- **Progressive Web App (PWA)** – Installable on mobile devices and desktops.
- **Persian Interface** – Fully localized Persian UI with RTL layout and Jalali calendar support.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Supabase
- PostgreSQL
- Progressive Web App (PWA)

## 🔒 Data & Security

Finance Cloud uses Supabase for authentication and cloud data storage.

Row Level Security (RLS) policies ensure that authenticated users can only access and manage their own financial records.

## 🚀 Getting Started

1. Clone or download the repository.
2. Create a project on [Supabase](https://supabase.com/).
3. Run the SQL commands provided in `supabase_setup.sql` using the Supabase SQL Editor.
4. Configure your Supabase Project URL and Publishable Key in `index.html`.
5. Deploy the project using GitHub Pages or another static hosting provider.

For detailed setup instructions, see [SETUP_FA.md](SETUP_FA.md).

## 📱 Progressive Web App

Finance Cloud supports installation as a Progressive Web App (PWA), allowing users to access it directly from their home screen.
