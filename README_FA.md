# نسخه اصلاح‌شده سایت مدیریت مالی

## مراحل اعمال اصلاحات روی Supabase فعلی

1. از داشبورد همان پروژه Supabase وارد **SQL Editor → New query** شو.
2. محتوای فایل `supabase_setup.sql` همین بسته را کامل اجرا کن. این اسکریپت جدول‌های موردنیاز و مجوزها/RLS را ایجاد یا اصلاح می‌کند و داده‌های قبلی را حذف نمی‌کند.
3. پس از دیدن پیام `Success`، فایل‌های سایت را روی هاست فعلی جایگزین کن:
   - `index.html`
   - `sw.js`
   - `manifest.webmanifest`
   - آیکون‌ها
4. سایت را با `Ctrl + Shift + R` یا `Ctrl + F5` تازه‌سازی کن و دوباره وارد حساب شو.
5. یک درآمد آزمایشی و سپس تنظیم موجودی را امتحان کن.

## چه چیزی در کد اصلاح شده؟
- خطای Supabase دیگر به پیام عمومی محدود نیست؛ خطای دسترسی/RLS، جدول یا ستون ناموجود، مقدار نامعتبر و مشکل شبکه با پیام روشن‌تری نمایش داده می‌شود.
- جزئیات خطا در Console مرورگر هم ثبت می‌شود.
- هنگام ذخیره موجودی، دکمه تا پایان درخواست غیرفعال می‌شود تا ثبت تکراری اتفاق نیفتد.

## نکته مهم
من به داشبورد زنده Supabase شما دسترسی ندارم؛ بنابراین وضعیت واقعی جدول‌ها و policyهای فعلی را از راه دور نمی‌توانم بخوانم یا تغییر بدهم. این بسته اسکریپت تعمیر را آماده می‌کند تا خودت در همان پروژه اجرا کنی. کلید داخل `index.html` از نوع Publishable است و نباید هیچ‌وقت کلید `secret` یا `service_role` را در فایل مرورگر قرار بدهی.
